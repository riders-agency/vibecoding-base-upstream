# Закреплённая верхняя навигация

## Коротко

Верхняя панель сайта остается доступной при прокрутке. Она может становиться компактнее, но не исчезает вместе с основными действиями. Закрепление не должно закрывать текст, якорные заголовки, активные поля и кнопки.

## Плохо

```text
Длинная страница каталога.
Прокрутка вниз → меню и поиск исчезли.
Нужно вернуться наверх ради корзины.
После фиксации шапка закрывает заголовок
и поле с ошибкой; меню прячется за таблицей.
```

## Хорошо

```text
Длинная страница каталога.
Сверху остается компактная навигация.
Поиск и корзина доступны при прокрутке.
Якорь и фокус видны ниже шапки.
Подменю поверх страницы, диалог поверх шапки.
```

## Почему

Постоянная навигация сокращает путь к следующему действию на длинной странице. Но высокая или неправильно закрепленная шапка может сделать содержание и клавиатурный фокус недоступными. Проверять нужно поведение при прокрутке и переходах, а не только положение панели на первом экране.

## Когда применять

Для страниц сайта с верхней основной навигацией. Это принятое требование справочника к таким страницам, а не обязанность любого сайта по WCAG. Специализированный полноэкранный просмотр, модальный сценарий и страница без общей шапки имеют отдельную область применения.

Во время открытого модального окна верхнее меню страницы не остается активным поверх него: управление принадлежит диалогу. На низком экране или при большом масштабе уменьшайте состав и высоту шапки, сохраняя доступ к основным действиям. Если закрепление даже в компактном виде делает задачу недоступной, зафиксируйте исключение для этого состояния и доступный способ навигации.

### Требования

- Закрепляйте существующую панель, по возможности через CSS. Для `position: sticky` задайте верхний отступ и проверьте границы контейнера и предков с `overflow`: панель не должна переставать держаться после короткого первого блока.
- При `position: fixed` предусмотрите место панели в раскладке. Высота может измениться из-за переноса текста, шрифта, локализации или сообщения над меню; фиксированное число пикселей для всех состояний ненадежно. Не создавайте прыжок страницы в момент закрепления.
- Учитывайте суммарную высоту шапки и других закрепленных панелей при переходе к якорю, ошибке формы и элементу фокуса. `scroll-padding-top` у области прокрутки или соответствующий отступ цели помогают, но результат нужно проверить с реальными переходами и фокусом.
- Для обычных элементов интерфейса обеспечьте полную видимость цели при фокусе; если элемент больше экрана, его начало и действия должны оставаться достижимыми прокруткой. WCAG 2.4.11 AA запрещает полное перекрытие фокуса; требование полной видимости обычной цели здесь строже этого минимума.
- Задайте согласованный порядок слоев: содержимое, панели, раскрытое подменю, модальный диалог. Не решайте каждый конфликт бесконечным увеличением `z-index`. Визуальная копия шапки, если она необходима, не создает дублирующих ссылок в порядке Tab и повторных ID.
- Не прячьте всю панель при прокрутке вниз, если принят этот стандарт. Допустимо плавное сокращение декоративной части; основные действия и фокус не пропадают и не перемещаются неожиданно во время ввода.
- Ссылки разделов остаются ссылками, раскрытие — отдельной кнопкой. Сохраняйте переход «К содержимому», видимый фокус, управление подменю с клавиатуры и на сенсорном экране.
- Учтите шапку совместно с нижними панелями, уведомлениями и открытой экранной клавиатурой. На 320 CSS px не должно требоваться горизонтально прокручивать всю страницу ради основных действий.

## Пример применения

В каталоге вымышленного магазина верхняя панель содержит логотип, каталог, поиск и корзину. При прокрутке исчезает только дополнительная декоративная строка. Переход к разделу описания товара располагает его заголовок ниже панели; окно добавления в корзину перекрывает шапку и временно делает её неактивной.

## Как проверить

- Прокрутите страницу до середины и конца в обе стороны: панель доступна, не выходит за границу короткого контейнера и не прыгает.
- Перейдите по якорю и ссылке «К содержимому», вызовите ошибку формы, пройдите Tab/Shift+Tab. Цель и действия видны, верхнее меню не закрывает фокус.
- Проверьте раскрытие меню, диалог, закрепленный заголовок таблицы и нижнюю панель одновременно: слои и отступы согласованы.
- Проверьте 320–390 CSS px, поворот, увеличенный текст, масштаб браузера и экранную клавиатуру. Содержание читается, навигация не занимает всю рабочую область.
- Отключите загрузку шрифтов и измените длину пунктов меню. Высота учитывается без скрытых кнопок и дублирующихся фокусируемых элементов.

## Человек

Определяет состав основной и компактной панели, исключения для специализированных экранов и проверяет удобство на реальных устройствах.

## Агент

Реализует закрепление, измеряемые отступы и порядок слоев. Проверяет контейнеры прокрутки, фокус, якоря, масштаб и переходы; отличает шапку сайта от заголовка таблицы.
