# Календарь и выдача по подходящим датам

## Коротко

Фильтр, сортировка и карточка используют одинаковое множество подходящих дат. У расписания есть обычный маршрут к следующим периодам, даже если автоматическая подгрузка прервалась.

## Плохо

```text
Фильтр выбрал июнь.
Порядок рассчитан по мартовской дате.
Карточка показывает весь сезон.
Следующий месяц доступен только по свайпу.
```

## Хорошо

```text
Фильтр вернул июньские отправления.
Ключ сортировки — ближайшее из них.
На карточке видны даты из результата.
Следующий месяц открывается ссылкой.
```

## Почему

Тур, рейс или событие могут иметь несколько дат. Ранжирование по первой дате всей карточки меняет смысл фильтра и даёт неправильную страницу результатов.

## Когда применять

Для списка с повторами или несколькими выездами. Для событий с началом и концом заранее определите, означает ли фильтр старт в диапазоне, пересечение либо полное попадание.

### Требования

- Определите часовой пояс, включение границ, значение диапазона и понятие ближайшей даты. Допуск «± N дней» применяется до отбора и передаётся через параметры состояния. Полная дата и длительность имеют понятное форматирование.
- Сначала отберите подходящие доступные отправления. Затем вычислите порядок объектов по ближайшему подходящему отправлению, используя устойчивый дополнительный ключ. Такой порядок применяется до пагинации на стороне источника выдачи.
- Показывайте подходящие даты и цены, связанные с выбранными условиями. Полное расписание может быть отдельным действием с явной подписью. Не скрывайте основную цену многоточием на узком экране.
- Для расписания с автоматической подгрузкой предоставьте обычную ссылку на следующий доступный период или страницу. Сохраняйте уже показанные записи, восстановление позиции и параметры фильтра при возврате.
- При изменении фильтра отбросьте запоздалые ответы старого поиска. Обозначайте загрузку и возможность повтора. Количество результатов показывайте там, где помогает, и указывайте точность. Удаление декоративного счётчика не меняет полноту данных.

## Пример применения

У двух походов есть мартовские и июньские выезды. После фильтра на июнь первым становится поход с ближайшим июньским отправлением. Следующий месяц открывается прямой ссылкой. На телефоне видны целиком цена и длительность.

## Как проверить

- Возьмите объект с датами до, в пределах и после диапазона, в том числе по границе и с допуском. Проверьте соответствующий порядок на всех страницах.
- Откройте расписание без JavaScript и пройдите все следующие периоды. Повторите после временного отказа запроса. Состав не теряется.
- На узком экране сравните показанные даты и цены с серверным ответом. Проверьте возврат из карточки и изменение фильтра во время загрузки.

## Человек

Подтверждает смысл периода и правила доступности, отображения и сортировки.

## Агент

Агент сверяет настоящие даты в запросе, порядке, карточках и последующих страницах.
